# Інтерфейс Rakurs, версія 2 (24.11.2026)

На скриншотах першої версії підтверджено працездатність 3 переглянутих
вкладок. Виявлені зауваження: багато порожнього місця, іконки вкладок без
підписів, повторюваний текст заглушок, спрощена схема енергетичних потоків
та недостатньо наповнена сторінка історії.

## Зміни v2
- Кожна вкладка містить **назву і піктограму** завдяки
  `show_icon_and_title: true`.
- Макет `sections`: максимум 2 колонки, компактне розміщення
  `dense_section_placement: true`, секції на всю ширину завдяки
  `column_span: 2`.
- «Огляд»: чітка шапка, статус моніторингу, 8 ключових індикаторів,
  окрема широка схема енергетичних потоків, стислий опис якості даних.
- «Інвертор»: три фази поруч, два MPPT, мережа, АКБ та стан обладнання.
- «Історія»: окремі блоки добових та місячних підсумків, без уявних
  графіків чи архіву.
- «Система»: стан підключення та обмеження безпеки.
- Використано **лише штатні картки** `markdown` і `heading`;
  жодних HACS чи нових мережевих доступів.

**Увага:** індикатор «Не захищено» на скриншотах користувача потребує
окремої перевірки в Chrome, незважаючи на успішний TLS-тест із Debian.
Не вводьте пароль, доки не підтверджено безпеку з'єднання. Перевірте
точний протокол у адресному рядку (https), Chrome → Site information
та DevTools → Security. Не використовуйте `--insecure` як вирішення.

## Оновлення існуючої панелі

Відкрийте **лише створену панель** «Rakurs — Енергомоніторинг»:
Редагувати панель → ⋮ → Редактор сирої конфігурації.
Спочатку збережіть її поточний YAML, потім замініть на повний вміст
`dashboard-rakurs.yaml` і збережіть.

Попередню редакцію збережено як `dashboard-rakurs-v1.yaml`.
Робота Home Assistant, Docker, Nginx, Odoo й інших панелей не змінюється.

Вміст файлу в GitHub **не синхронізується автоматично** з UI-панеллю:
заміна в браузері необхідна.

## Що означають прочерки

`sensor.rakurs_*` — планові імена, що ще не підтверджені реальним
Home Assistant. Порожні значення не дорівнюють нулю. До підтвердження
типу Teltonika gateway, Modbus Slave ID та регістрів інвертора Deye
не додавайте підроблену телеметрію, аварійні пороги чи сервіси керування.

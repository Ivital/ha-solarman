# Панель RAKURS — початковий інтерфейс

Панель **вже створена** в інтерфейсі Home Assistant користувачем. Файл
`dashboard-rakurs.yaml` — **повний Lovelace-конфіг тільки цієї панелі**,
не `configuration.yaml` і не Docker Compose.

## Установлення без зміни сервісів

1. Відкрити `https://rakurs.zakryttya.org.ua` і вибрати створену панель
   «Rakurs — Енергомоніторинг» у бічному меню.
2. Перейти в режим **Редагувати панель** → меню **⋮** →
   **Raw configuration editor / Редактор сирої конфігурації**.
3. Якщо там уже є дані, зберегти копію перед заміною.
4. Замінити лише вміст редактора **цієї новоствореної панелі** на
   `dashboard-rakurs.yaml`. Зберегти, далі натиснути **Готово**.
5. Повинно бути чотири вкладки: **Огляд**, **Інвертор**,
   **Історія**, **Система**.

Редактор створеної через UI панелі зберігає налаштування у Home Assistant,
а не автоматично синхронізує їх із GitHub. Не редагуйте
`/config/.storage/lovelace*` вручну і не перезаписуйте стандартну
системну панель «Огляд».

## Точність і відображення

Жодних тестових цифр. Поки немає телеметрії, усі показники
позначено **—**, а розділи історії є інформаційними.
Використано лише штатні картки Home Assistant:
`sections`, `heading`, `markdown`; не потрібні HACS або додаткові
плагіни.

Імена `sensor.rakurs_*` — **майбутні псевдоніми**, вони не були
виявлені в реальному Home Assistant. Після підтвердження Teltonika Modbus
TCP gateway, Modbus Slave ID і карти регістрів Deye їх необхідно
замінити фактичними Entity ID; до того часу не заповнювати показники
синтетичними даними.

Запис у інвертор не використовується. У панелі відсутні керувальні
картки та сервіси запису.

## Подальше

Після підтвердження вигляду панелі — перевірити режим Teltonika та
додати реальні показники Deye, потім графіки й енергобаланс.

# Rakurs UX v2 — повний редизайн
Дата: 26.11.2026.

Причина: попередній світлий CSS перекривав лише частину компонентів, а окремі серверні сторінки залишалися темними.

Зміни: токени світлої/темної теми для головної, двох Deye, Modbus, історії, таблиць, налаштувань, подій та RS485; окремі темізовані сторінки входу і /deye; нова головна hero + status strip + основні KPI + коротка навігація + два інвертори + схема + графіки.

Немає апаратного опитування, змін Modbus, SQL DML/DDL, вигаданих живих показників. Статична SSR головна зберігає показники MySQL при збої API.

Перевірки: регресійні DOM та CSS тести, два режими теми, маніфест релізу, node --check, SHA-256 локального і публічного HTTPS. Всі зміни через GitHub -> CI -> штатний деплой.

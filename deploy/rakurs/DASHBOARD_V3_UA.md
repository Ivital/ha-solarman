# RAKURS v3 · графічна схема потоків

Додана SVG-схема `assets/energy-flow.svg`: сонячні панелі PV1/PV2,
гібридний інвертор Deye, акумулятор, мережа та навантаження.
Картка `picture` зображає **лише можливі електричні зв'язки**:
пунктирні стрілки НЕ означають фактичну генерацію, імпорт чи експорт,
а прочерки НЕ є нулем. Жодних фіктивних вимірювань.

## Встановлення

1. На Debian:
   ```bash
   cd ~/deye-monitoring-src
   git pull --ff-only
   bash deploy/rakurs/install_diagram.sh
   ```
   Перевіряються Docker bind mount, справжність каталогів і SHA-256;
   скрипт копіює тільки SVG у `/config/www/rakurs`. Він не змінює
   Nginx, Docker Compose, Odoo, Ergodata чи параметри Deye.
2. Перевірте в браузері
   `https://rakurs.zakryttya.org.ua/local/rakurs/energy-flow.svg?v=3`.
   За потреби вперше створений `/config/www` вимагає перезапуску лише
   Home Assistant; якщо скрипт показує 404, **не імпортуйте YAML**, доки
   ресурс не поверне 200.
3. У створеній UI-панелі **Rakurs — Енергомоніторинг** відкрийте
   «Редагувати → ⋮ → Редактор сирої конфігурації». Збережіть поточний
   YAML, вставте `dashboard-rakurs.yaml` (v3), збережіть.
4. Для відкату імпортуйте попередню конфігурацію
   `dashboard-rakurs-v2.yaml`. SVG може залишитися у папці `www`.

Панель не синхронізується з GitHub автоматично. На етапі v3
застосовано штатний Home Assistant `picture` без додаткових плагінів.
Після достовірного Modbus-читання візуалізацію можна зробити динамічною.
